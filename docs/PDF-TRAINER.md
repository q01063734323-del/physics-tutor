## Документ и подсчёт

Источник: «ЕГЭ-2026. Физика. Отличный результат. Учебная книга участника ЕГЭ», под редакцией М. Ю. Демидовой. SHA-256: `0a7b3ff6ccc721c16c4bd7819d08620b8a0d81f0f2a4cfd286ab0c1cef86043a`.

- 488 страниц, около 95 MiB. PDF состоит из сканов без встроенного текстового слоя.
- Все страницы сохранены и распознаны локально. Внешние платные OCR/API не использовались.
- Выделена 1481 запись упражнения. Составные упражнения считаются одной записью; это не подтверждённое количество отдельных подзаданий. Надпись «Более 1600 заданий» на обложке не использована как результат подсчёта.
- Для каждой записи просмотрены условие, рисунки и соответствующий ответ/решение при наличии. 1460 записей прошли сверку с источником; у 21 обнаружены противоречия, неоднозначность, неполное решение либо повтор.
- 175 условий представлены текстом с формулами; 1285 — проверенными фрагментами оригинального условия. Полной текстовой расшифровки всех задач нет. Скан сохраняет рисунки, таблицы, единицы и математические обозначения.
- Обработаны 149 записей тренировочных таблиц и 14 условий с продолжением на следующей странице.
- Связаны 1065 кандидатов ячеек ответов и 98 кандидатов решений. Это вспомогательные данные импорта, а не количество автоматически утверждённых эталонов. Непроверенный OCR не используется как правильный ответ.
- Подробное решение доступно только там, где оно присутствует и проверено. Остальные решения не сочинялись.
- Дубликатов ID нет. Найден один содержательный повтор в самом источнике; повторная запись исключена из практики и сохранена для аудита.

## Архитектура и интерфейс

Проект сохраняет Next.js App Router, React, TypeScript и Firebase. Существующий банк из 50 задач подключается через адаптер с прежними ID. Авторизация, кабинеты, домашние задания, Cloudinary и виртуальный класс в рамках этого импорта не заменялись.

Единая модель задачи содержит стабильный ID и версию, раздел и несколько тем, номер ЕГЭ с доказательством сопоставления либо `null`, условие, изображения, тип ответа, эталон и решение при наличии, страницы источника, статус сверки и прав. Одна задача хранится один раз независимо от количества тем.

В интерфейсе есть независимые режимы «По номерам / По темам», поиск, счётчики, фильтр прогресса, последовательное решение и возврат к ошибкам. Эталоны и исходные решения показываются после попытки. Составные числовые ответы вводятся через пробел или точку с запятой; поддерживаются десятичная запятая и научная запись. Задачи с развёрнутым ответом не получают автоматического зачёта по совпадению текста.

Сканы можно увеличивать и открывать отдельно. KaTeX использует безопасный режим `trust: false`. Попытки привязаны к ID и версии содержимого: старое решение не переносится автоматически на изменённое условие. В закрытом предпросмотре прогресс хранится только на устройстве, без синхронизации с аккаунтом.

Печатные номера сохраняются как метки сборника 2026 года, а не как гарантированное соответствие будущему экзамену. Номер контрольного упражнения внутри главы не считается номером ЕГЭ. Ранее отдельно проверены №1 и №2 по материалам ФИПИ 2027; другие номера не переназначались наугад. Ссылки: [материалы ФИПИ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory), [архив по физике 2027](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/fi_11_2027.zip).

## Импорт и защита черновиков

Материалы находятся в `.local/pdf-imports/` и исключены из Git и трассировок production. В полном наборе хранятся все исходные страницы, вырезки, manifest, пакеты по главам, профиль границ и связей, журнал сверки и отчёты. Частный журнал содержит проверенные ответы, контрольные суммы условий и отдельные контрольные суммы решений. Изменение соответствующего фрагмента отменяет прежнюю сверку.

Импорт поддерживает продолжение обработки по страницам, стабильные ID, хеши изображений, повторный запуск без дублей, корректировки границ и привязку коротких решений через `solutionFragmentOverrides`. Последняя повторная подготовка: **0 добавлено, 0 обновлено, 1481 без изменений**.

Локальная практика принимает только записи со статусом `source_checked`. Это результат сверки с PDF, а не отдельное утверждение преподавателя. При преобразовании в учебную модель сохраняются `review.status: needs_review` и `rights.status: unknown`; публикационный фильтр их отвергает. 21 спорная запись не проходит даже в локальную практику.

Страница `/teacher/import-preview` и API её изображений работают только в режиме разработки с флагом и разрешённым локальным адресом. В production они возвращают 404 даже при установленном флаге. Ответы API имеют приватные заголовки без кеширования. Эталоны локального прототипа доступны в данных браузера: для настоящего контроля результатов нужна серверная проверка перед будущим публичным подключением.

## Как открыть

Из корня проекта:

```sh
PDF_IMPORT_PREVIEW=1 WATCHPACK_POLLING=true npm run dev -- --webpack --hostname 127.0.0.1 --port 3217
```

Открыть `http://localhost:3217/teacher/import-preview` на этом компьютере. По умолчанию выбран набор «Практика · проверено 1460». Полный архив, пилот и старый банк доступны через переключатель. Это локальный адрес для проверки, не ссылка для учеников. На момент передачи сервер запущен; после остановки его потребуется запустить снова.

Для повторной подготовки нужны Poppler, Python с pypdf/Pillow, исходный PDF и частные планы/журналы:

```sh
python3 scripts/pdf/prepare-bank.py '/путь/к/исходному.pdf'
python3 scripts/pdf/test-review-contract.py
python3 scripts/pdf/verify-reviewed.py
```

Частные планы и материалы книги не включены в репозиторий. На другой машине их нужно предоставить отдельно. OCR использует локальный tesseract.js, заданный через `TESSERACT_MODULE`; распознавание не добавлено в клиентские зависимости.

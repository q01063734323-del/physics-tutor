# Physics Studio 2.0 — аудит и принятые решения

Аудит исходной реализации выполнен перед изменениями; сведения о браузерных ограничениях сопоставлены с установленным LiveKit client 2.23.0. Статус на 20 ноября 2026: реализация и автоматические проверки выполнены, реальный сеанс двух устройств для этой версии не подтверждён.

## Ограничения измерений

getSettings/getCapabilities показывают локальный захват. Sender/receiver getStats показывают реально кодируемый и получаемый поток; они могут отличаться от захвата и профиля. Отсутствующее поле обозначается «Недоступно». Битрейт/FPS по счётчикам доступны после двух измерений. Потери вычисляются по приращениям, сброс счётчика не превращается в отрицательные значения. Диагностика запускается только при открытой панели, раз в 2 секунды, и не отправляет логи на сервер.

Время «полученный пакет → кадр» не является полной сетевой задержкой между двумя устройствами. JS heap, если API доступен, не равен памяти всего процесса. Измерений длительного физического урока пока нет.

## Совместимость и отказоустойчивость

Safari получает захват без жёсткого разрешения; это учитывает описанную в исходниках установленного SDK проблему screen constraints Safari 17. Запрос профиля не обещает Full HD. Отмена выбора экрана не запускает повторный диалог и не разрывает звонок. Смена профиля использует текущий LocalVideoTrack и его sender; смена расположения не пересоздаёт Room. Неподдерживаемые параметры дают предупреждение и применяются при следующем запуске показа.

Ошибки PDF и доски изолированы от управления медиа. Обработчики/таймеры удаляются при размонтировании. Проверки cleanup/pending-connect выполнялись с подставленными медиаобъектами; длительный реальный звонок и аппаратные утечки памяти остаются приёмочными проверками.

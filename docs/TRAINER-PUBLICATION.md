# Публикация банка ЕГЭ — 18 ноября 2026

Публикацию выбранного набора разрешил владелец проекта в чате. 21 спорная запись пропущена по его указанию. Это запись о согласовании размещения, а не заявление об открытой лицензии издательства.

## Подготовленный результат

- `/trainer`: 1460 задач, два режима поиска, темы и подтверждённые печатные номера сборника 2026 года.
- Каталог по 30 записей; 49 страниц полного набора. Последовательная практика охватывает весь выбранный набор.
- 1687 WebP-фрагментов условий, рисунков и решений. Сжатие без потерь: каждый RGB-пиксель и размеры сверены с исходными PNG. Объём — 284 MiB; изображения загружаются по мере открытия, не всем банком сразу.
- Ответы и решения исключены из каталога. `/api/trainer` принимает ID, версию и ответ, проверяет на сервере и возвращает эталон/решение после попытки. Развёрнутые ответы требуют ручного разбора.
- Исходный PDF, полные страницы, OCR и закрытые замечания не включены в публикационный пакет. Необработанный OCR также исключён: соседние колонки в книге могут содержать ответы.
- Поиск работает по текстовым условиям, темам, разделам и названиям упражнений. Условия, сохранённые только сканом, не имеют полной текстовой индексации.
- Кнопки перехода добавлены на главную и в прежний банк. Старые 50 задач, ручной ввод преподавателя и маршруты сохраняются.
- Прогресс хранится в браузере, отдельно для гостя и каждого вошедшего пользователя. Облачная синхронизация нового банка не добавлялась. Сохранённые результаты других разделов не изменяются.
- Firebase, правила Firestore, Cloudinary и виртуальный класс не менялись. Платные сервисы и новые зависимости не добавлены.

## Отправка и проверка Render

Пакет сохранён локальным коммитом `26976de` в ветке `feature/student-management`. Автоматическая проверка отклонила `git push`: разрешение на публикацию на сайте сочтено недостаточно явным для передачи конкретного пакета (1460 заданий с ответами/решениями и 1687 изображений) в открытый репозиторий `q01063734323-del/physics-tutor`. После этого владелец явно подтвердил передачу именно этого пакета в открытый GitHub-репозиторий: «Да, разрешаю загрузить этот пакет в публичный GitHub». Ограничение по согласованию устранено. Повторная отправка была разрешена автоматической проверкой, но GitHub отклонил подключение: в CLI нет сохранённой авторизации (`could not read Username`). Загруженных SSH-ключей также нет. Поэтому удалённая ветка не обновлена. Требуется обычный вход в GitHub либо `Push origin` из уже авторизованного GitHub Desktop; пароль/токен в чат не запрашивается.

Панель Render и публичный сервис во время предварительных проверок отвечали тайм-аутом; доступа к управлению открытым Chrome нет. Успешный локальный прогон не считается подтверждением обновления публичного сайта. После подтверждения и отправки требуется отдельно проверить обновление Render.

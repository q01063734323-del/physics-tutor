# Physics Library → Studio 2.0 — состояние работы

20 ноября 2026. Порядок пользователя соблюдён: сначала Physics Library, затем Studio 2.0. Ветка `feature/physics-library-studio-2`, база `4d4ec7216c9c0c19325dee5137730adb0038565c`. Первый блок закоммичен как `ecc9540`.

Реализация и ограничения подробно описаны в [итоговом отчёте](LIBRARY-STUDIO-2-REPORT.md); подтверждённые причины и гипотезы разделены в [аудите студии](STUDIO-2-AUDIT.md).

Добавлены приватная библиотека, PDF-презентации, единая потоковая Canvas-доска, настоящая PDF-версия с пометками, выдача/отзыв материалов, восстановление истории того же ученика, долговременные локальные очереди, профили качества независимых камеры/экрана, реальные необязательные WebRTC-метрики, Whiteboard/Cinema/Studio и zoom. Подключены бесплатные PDF.js/pdf-lib. Платные услуги и новые серверы не включены; ограниченный адаптер PDF использует существующие квоты Firestore.

Финальные уточнения: повторяемое физическое удаление с удержанием квоты до успеха; чистка временных гостевых материалов при завершении и ограниченно при загрузках; атомарное восстановление страниц с сохранностью при сбое; flatten прошлой истории без наращивания цепочки; ограничение страниц/байтов пометок; защита от поздних удалённых штрихов; отмена и последовательное выполнение PDF canvas render; отдельный жизненный цикл интерфейса при смене аккаунта/комнаты; честное сообщение об отмене screen picker.

Автоматические проверки: полный npm test, TypeScript, ESLint и webpack production build. Новые тесты исполняют настоящий библиотечный API/pdf-lib с подставленным Firebase, роли/expiry/cleanup, атомарное восстановление и failure retention; профили/constraints/stats с подставленным media; долговременную очередь с подставленным transport/storage. Экспорт настоящего синтетического PDF проверен визуально Poppler на crop box и четырёх поворотах.

Приёмочные ограничения: встроенный браузер не подключился к безопасному loopback-серверу (connection refused). Реальные устройства, iPhone PWA, двухсторонний звонок новой версии, качество/задержки/длительная память и точная причина синего артефакта не подтверждены. В локальном окружении отсутствуют приватные параметры Firebase Admin/LiveKit для интеграционного теста. Полную приёмку Studio 2.0 не объявлять завершённой. Версия на Render и правила Firebase не публиковались.

Существующие локальные `COMMAND-CENTER-DEPLOYMENT.md` и `screenshots/command-center-render.jpg` относятся к прежней задаче и в коммит новой работы не включаются.

Архитектура: существующие Next/React/Firebase и банк опубликованных задач. Отдельный детерминированный движок fixed-step 20 Hz для движения, мостов, целей, снарядов, башен, карты/рука/очередь, ботов и результата. Canvas/RAF для арены, оригинальные SVG портреты/спрайты, без тяжёлого Phaser и нового игрового сервера. Задачи и проверка ответов на существующем серверном банке; игроку нет регенерации энергии. Награды за ответы подтверждаются сервером; результат и XP сохраняются только после серверного воспроизведения событий матча. Преподаватель управляет доступностью/темами/наградами через авторизованный API. Гостевая практика честно отделена от облачного профиля.

Этапы: 1) движок+проверки основного боя; 2) адаптер ЕГЭ/API/защита начислений; 3) игровой интерфейс/боты/исходные SVG/звук/мобильное управление; 4) профиль, коллекция/улучшения/арены, преподаватель; 5) общие тесты/сборка/доступный browser QA/отчёт.

Делегированы только ограниченные ассеты и исследование существующей архитектуры по указанию Sites workflow; основной движок/интеграция остаются в текущей задаче. Никаких production записей Royale, импорта банка или деплоя игры не выполнять.

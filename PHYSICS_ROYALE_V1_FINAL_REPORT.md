# Physics Royale 1.0 — отчёт о локальной версии

Версия для просмотра доступна в отдельной ветке `physics-royale-v1`. Исходная ревизия проекта — `b5069d6`. Изменения и ресурсы находятся в локальной рабочей копии.

## Что вошло

- Существующая игра против бота использует 16 карточек, прежние значения энергии, урона и другие параметры, прежние правила боя и тот же каталог из 1361 проверяемой задачи. Формулы используют существующий рендерер, а ответы проверяет существующий API. Из экрана результата можно повторить ошибки с проверкой ответа и пояснением, когда оно есть в банке.
- Все 16 карточек имеют отдельные иллюстрации. В 3D используются модели бойцов, варианты охотников и раздельные эффекты двух заклинаний. Для Пламени кометы подключён прежний модуль огня. У Звёздного обвала отдельное каменное ядро и цветовой профиль шлейфа.
- Sky Arena 4.0 основана на геометрии 3.0. Сохранены два острова, оба моста и шесть башен. Камеры, пропорции островов и положения башен адаптированы к прежней сетке боя. В GLB — облака, флаги, волны, подсветка, кристаллы и атом. В Three.js добавлены анимированный рельеф воды и атмосферная дымка. Версия 3.0 хранится отдельно.
- Меню, колода, коллекция, карточки, панель задач, шкала энергии и окно результатов оформлены в синей и фиолетовой палитре с золотистыми акцентами. Счётчик загрузки отражает готовность групп ресурсов. При сбое 3D работают облегчённые модели и классический режим.
- High и Medium используют анимированную арену и GLB. Medium снижает бюджет теней, частиц и разрешения. Low использует облегчённую арену и модели, режим может открыться без загрузки тяжёлых ресурсов. Цвет команды читается по кольцу у основания и полосе здоровья.

Справочные изображения, скрипты, таблицы ресурсов и проверок входят в архив. Карточки в игре используют иллюстрации WebP из этих рендеров и прежних утверждённых моделей.

## Результаты проверок

- `npm test`, `npm run test:royale`, TypeScript и сборка Next.js через Webpack прошли. Тесты образовательной части используют опубликованный банк и подменяют доступ к Firebase.
- Chrome на Apple M4. Открытие игры, просмотр 16 карточек, использование карты, неверный и верный ответ, начисление энергии, пауза, результат, повтор ошибки, новый матч и переключение 2D/3D проверены в гостевой практике. Получены снимки на 1440, 768, 412, 390 и 320 CSS px. Ширина страницы совпала с шириной окна.
- Отдельная проверочная сцена использует тот же рендерер и игровой движок. Успешно размещены 16 карточек. В сцене с 20 бойцами измерено около 60 кадров/с в течение короткого замера на Apple M4. High и Medium дали около 449–453 вызовов отрисовки и 674 тыс. треугольников, Low — 107 вызовов и 29 тыс. треугольников. Результаты не описывают долгую игровую сессию или холодную загрузку на телефоне.
- В обычном бою телеметрия показала 60 FPS на 1440 CSS px и 55–56 FPS на эмулированных узких экранах в Chrome на том же Mac. Playwright WebKit открыл 3D на ширине 390 CSS px. Автоматизация установленного Safari требовала включить управление браузером, поэтому проверка через Safari WebDriver не выполнена.
- Sky Arena — примерно 4,55 МБ, 146 425 треугольников, 131 примитив, 4 встроенные текстуры. Все GLB вместе — около 30,8 МБ, загрузка происходит в игре. В архиве есть раздельные метрики размеров, примитивов, материалов, текстур и клипов. Снижение графики сокращает обработку кадра. Для режима Low, включённого после High, загруженные модели могут сохраняться до ухода из матча.
- Облачные матчи, реальные телефоны и долговременное использование памяти нуждаются в отдельной проверке. Текущая версия моделей стилизована для игровой камеры. Сложные формы оперения феникса, пламени и льда, а также складки костюмов остаются проще утверждённых концептов. Sky Arena 4.0 развивает сетку, кадрирование и материалы исходной сцены, часть природных форм и архитектуры унаследована от 3.0.

## Запуск

1. Откройте рабочую копию ветки `physics-royale-v1` либо восстановите её из `physics-royale-v1.bundle` в копии проекта с базовой ревизией `b5069d6`.
2. Установите зависимости через `npm ci` и задайте публичную конфигурацию Firebase из вашего проекта. Для изолированной гостевой проверки использовались локальные тестовые значения, облачные учётные записи не подключались.
3. Запустите `npm run dev -- --webpack --hostname 127.0.0.1`. Откройте `/royale`, выберите «Объёмный 3D» и нажмите «В бой».
4. Для сборки используйте `npm run build -- --webpack`. Для проверки только игровых и учебных сценариев используйте `npm run test:royale`. Полный набор тестов также использует шаблон `.env.example` из исходной рабочей копии, который исключён из Git.
5. Next.js выдал предупреждение безопасности для установленной версии. Обновление зависимостей следует выполнить и протестировать отдельно перед публикацией.

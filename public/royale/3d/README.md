# Оригинальные ресурсы Physics Royale 3D

Все персонажи, башни и арена созданы процедурно специально для этого проекта.
Ресурсы Supercell и сторонние игровые модели не используются.

- `citadel-crystal.glb` — оригинальная композиция из каменного основания, золотой оправы и парящего кристалла; 9 588 байт. Содержит анимацию перемещения и вращения.
- Воспроизводимый исходник: `scripts/build-royale-glb.mjs`. Пересоздание: `node scripts/build-royale-glb.mjs` из корня проекта.
- Персонажи и башни: `src/lib/royale/three/models.ts`. Это составные объёмные модели с лицами, конечностями, оружием и суставными анимациями.
- Окружение: `src/lib/royale/three/arena.ts`.
- Упрощённые цветные модели низкого качества: `src/lib/royale/three/lod.ts`, автоматически получаются из тех же оригинальных силуэтов.

Three.js и его GLTFLoader/GLTFExporter используются по лицензии MIT, включённой в установленный пакет. Внешние текстуры, платные библиотеки и сервисы генерации моделей не требуются.
